Claude Code「自产自审」：90% 代码 AI 写、AI 审，回滚率反降四成

Anthropic 工程团队博客披露：Claude Code 代码库约 90% 的代码由 Claude 自己编写，大部分审查也由 AI 完成。每日变更量从 5 月约 2500 次涨到 9 月超 3 万次，合并 PR 数量翻倍的同时，回滚比例反而下降超 40%。做法是把「逐行阅读」拆成七层自动化检查（pre-PR Agent 检查、并行 AI 找 Bug 投票、独立安全评审），人工只在高风险节点终审；审查意见采纳率从 16% 升至 54%，平均审查轮数从 2.08 降至 1.32。

为什么值得关注 · Agent 量产代码后「谁来审」成为工程组织的真瓶颈，Anthropic 给出了目前最完整的公开答案：审查范式从『人有没有看过』转向『哪里会出事、该由谁拦』——这是 AI 时代研发流程重构的标杆样本。

浙大 EMem-Bench：具身智能体「看见 ≠ 记住」，外部记忆成功率 35.3%→58.9%
