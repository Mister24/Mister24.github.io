算法 —— 动态规划

2020-10-24

问题说明

&nbsp;&nbsp;动态规划在寻找有很多重叠子问题的情况下的最优解时有效，将大问题分解为子问题，最核心的部分是利用历史记录来保存中间子问题的答案，避免重复计算，这些历史记录需要进行存储，需要借助于一定的数据结构，如一维数字或者二维数组等。

&nbsp;&nbsp;如果一个问题满足以下2点，那么它就能用动态规划解决。

1. 问题的所有答案构成一个潜在的数列

2. 大问题最终可以由小问题来递推得到，f(n) 可以从f(n-1)获取到。

&nbsp;&nbsp;当然，上面的提炼，除了把新手直接吓懵，没有任何作用，所以我们从基础入手，逐步揭开 "动态规划"的神秘面纱。

举个例子

跳台阶问题

/**
 * 一只青蛙一次可以跳上1级台阶，也可以跳上2级。求该青蛙跳上一个n级的台阶总共有多少种跳法（先后次序不同算不同的结果）。
 *
 * DP问题：
 * （1）确定数组含义：dp[i]表示跳到第i阶的方法数；
 * （2）找出数组元素间的关系：跳到第i阶，可以一步跳上来，也可以两步跳上来，所以dp[i]=dp[i-1]+dp[i-2]；
 * （3）找出初始值：dp[0]=1,dp[1]=1；
 *
 * @author mr.24
 * @version Id: Solution, v 1.0 2020/10/25 下午9:54 Exp $$
 */
public class Solution {
    public static void main(String[] args) {
        System.out.println(jump(-1));
        System.out.println(jump(0));
        System.out.println(jump(1));
        System.out.println(jump(2));
        System.out.println(jump(3));
        System.out.println(jump(4));
        System.out.println(jump(10));
    }

    public static int jump(int number) {
        if (number < 0) {
            return 0;
        }
        if (number >= 0 && number <= 2) {
            return number;
        }

        int dp[] = new int[number];
        int temp = 0;
        int dp1 = 1;
        int dp2 = 2;
        for (int i = 3; i <= number; i++) {
            temp = dp1 + dp2;
            dp1 = dp2;
            dp2 = temp;
        }

        return dp2;
    }
}

求解思路

1. 【最优子结构】找到最优子结构(子问题)，如F(10)可以分成F(9),F(8)两部分。

2. 【状态转移方程】描述状态转移方程(用子问题的解来表示原问题），如F(N) = F(N-1)+F(N-2)

问题的边界,如，F(1)=1,F(2)=2.

3. 最终实现一般有：传统递归方法、备忘录法、动态规划法。

明确 base case -> 明确「状态」-> 明确「选择」 -> 定义 dp 数组/函数的含义。

# 初始化 base case
dp[0][0][...] = base
# 进行状态转移
for 状态1 in 状态1的所有取值：
    for 状态2 in 状态2的所有取值：
        for ...
            dp[状态1][状态2][...] = 求最值(选择1，选择2...)
